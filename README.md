# Suellen Rodrigues — Personal Trainer

Site oficial da marca pessoal **Suellen Rodrigues | Personal Trainer**.

## Estrutura atual

```text
Suellen_Rodrigues/
├── index.html          # Página principal do site
├── favicon.png         # Favicon da marca
├── logo-completo.png   # Logo completo / arquivo de apoio
├── logo-icone.png      # Ícone da marca / arquivo de apoio
└── README.md           # Documentação do projeto
```

## Publicação

O projeto é um site estático e pode ser publicado diretamente pelo **GitHub Pages** usando a branch `main` e a pasta raiz `/`.

## Organização

- `index.html` é o único ponto de entrada da aplicação.
- A cópia antiga do HTML foi removida para evitar duplicidade.
- O arquivo `Assets` que era apenas um placeholder foi removido.
- Os arquivos de identidade visual permanecem na raiz para preservar os recursos atuais do projeto.

## Próxima etapa recomendada

Quando houver necessidade de manutenção maior, os estilos e scripts incorporados no `index.html` podem ser separados em `assets/css/style.css` e `assets/js/main.js`. A separação deve ser feita preservando o visual e o funcionamento atuais.
